# System Brightness Controller using Hand Gestures

A real-time Computer Vision project that enables users to control system brightness using simple hand gestures through a webcam. This project leverages hand tracking technology to create a touchless and intuitive human-computer interaction experience.

---

## 📖 Project Overview

The **System Brightness Controller using Hand Gestures** is developed using Python and Computer Vision libraries. It detects hand landmarks through a webcam feed and dynamically adjusts the system brightness based on the distance between the thumb and index finger.

This project demonstrates the practical implementation of:
- Hand Gesture Recognition
- Real-Time Video Processing
- Human-Computer Interaction (HCI)
- Computer Vision using AI-based tracking

# 🖐️ How It Works

- The webcam captures live video input.
- MediaPipe detects hand landmarks in real time.
- The distance between the thumb tip and index finger tip is calculated.
- The calculated distance is mapped to the system brightness range.
- Brightness increases or decreases according to finger movement.

---

# 🎯 Gesture Functionality

| Hand Gesture | Action |
|--------------|--------|
| Fingers Close Together | Decrease Brightness |
| Fingers Far Apart | Increase Brightness |
